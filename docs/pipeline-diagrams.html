01 · เก็บและเตรียมข้อมูล

แยกสายข้อมูลตลาดออกจากเอกสารข่าวและรายงาน แต่ละสายรักษา provenance และ null ตามต้นทางก่อนส่งต่อไปการวิเคราะห์

เทคนิคเด่น

เก็บ source URL / publication date, ซ่อม encoding และ deduplicate เอกสาร, เก็บตาราง BLS เป็น raw blocks และใช้ LLM classify ข่าวพร้อม evidence/audit metadata

02 · Historical replay และ Monte Carlo simulator

แยก observed quotes ออกจากกฎพฤติกรรมที่เป็นสมมติฐาน ก่อน replay ให้เกิด ledger สังเคราะห์ที่ทำซ้ำและกระทบยอดได้

เทคนิคเด่น

Event-driven historical replay, per-cohort/per-portfolio seeded RNG, monthly decision grid, as-of PriceBook จำกัด look-ahead, cashflow ledger แยกจาก P&L และ weighted-average-cost accounting

03 · Chunking, Embedding และ Retrieval Evaluation

เปรียบเทียบโครงสร้าง chunk บนคำถามเดียวกันด้วยโมเดลเดียวกัน และใช้ exact cosine เพื่อวัดผล chunking โดยไม่ปะปน ANN index

เทคนิคเด่น

Structure-aware chunking รักษาหัวข้อรายงาน; Adaptive ได้ evidence recall@10 สูงสุด 83.3%; structure-aware ให้ Evidence MRR สูงสุด 0.640 — ไม่มีวิธีชนะทุก metric

04 · สร้าง Vector Store บน Qdrant

Notebook ตรวจ hash และ checkpoint ก่อน batch upsert; จำนวนจุดใน cloud และไฟล์ checkpoint ที่เหลือต้องตรวจให้ตรงกันก่อนเชื่อว่า index ปัจจุบันครบ

เทคนิคเด่น

ตรวจ text hash และ vector dimension, cache เพื่อ resume embeddings, chunk-level checkpoint สำหรับ upsert และ exact count verification; อย่าฝัง API key ใน notebook/output ที่แชร์

05 · Retrieval-Augmented Generation และการประเมิน

ผสาน lexical และ semantic retrieval, rerank evidence แล้วสร้างคำตอบที่เก็บ citation; วัด retrieval, citation, schema และ latency แยกกัน

เทคนิคเด่น

Dense + BM25, RRF fusion, Jina reranking, citation-preserving prompt (A2) และ evidence-coverage/schema controls (A3). Citation ID ถูกต้องไม่ได้ยืนยันว่า claim ได้รับการสนับสนุนจริง

06 · Static data bundle ไปยัง Vercel และ Render

Build package รวม snapshot ที่ export ล่วงหน้า; Vercel API routes อ่านไฟล์ JSON ที่ trace เข้า deployment และ stream คำตอบจาก GAIB-1 บน Render — ไม่มี database หรือ persistent disk

เทคนิคเด่น

Build-time Parquet validation, deterministic gzip JSON, SHA-256 provenance, Next.js output tracing, read-only paginated API และ SSE proxy; Render ใช้เฉพาะ Python runtime โดยไม่มี application database
