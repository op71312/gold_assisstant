# UX Audit: Gold Assistant (evidence-based, 2026-10-28)

Method: superpowers "Look Before You Ask" — อ่านโค้ดทั้งหมด (page.tsx, Sidebar, views/*, ChatPanel) + ถ่ายภาพหน้าจอจริงด้วย agent-browser (desktop 1600px, mobile 390px, รันวินิจฉัยจริง) ก่อนตัดสินใจออกแบบใหม่ ห้ามแก้โดยไม่มี evidence

## ปัญหาที่พบ (เรียงตามความรุนแรง)

### A. โครงสร้างข้อมูล (IA) และการนำทาง
1. **แท็บ "หน้าแรก" ไม่ใช่หน้าแรก**: แอปเปิดที่แท็บ `portfolio` (activeNav default = 'portfolio') แต่เมนูมี "หน้าแรก" แยกไว้ — ชื่อเมนูสร้างความสับสน ผู้ใช้ใหม่กดเข้าเว็บแล้วเจอแท็บพอร์ตที่มี Scenario Picker บังข้างหน้า
2. **8 แท็บรวดเดียว ไม่มีกลุ่ม**: หน้าแรก / Gold Assistant / พอร์ต / วิเคราะห์ / ข่าว / ข้อมูลตลาด / รายละเอียดโปรเจกต์ / ตั้งค่า — ความต่างระหว่าง "วิเคราะห์" กับ "ข้อมูลตลาด" กับ "ข่าว" ไม่ชัดสำหรับมือใหม่
3. **รายชื่อทีม 5 แมวซ้ำ 3 ที่**: Sidebar การ์ดทีม + HomeView รายชื่อ + กราฟ Gold Assistant — พื้นที่จอถูกใช้ซ้ำกับเนื้อหาเดิม

### B. Top bar มี dead controls
4. **ช่องค้นหาไม่ทำงาน**: placeholder สัญญาว่า "ค้นหา ข่าว, บริษัท, หรือคำถาม..." แต่พิมพ์แล้วไม่เกิดอะไรเลย (affordance โกหก)
5. **กระดิ่งแจ้งเตือนไม่ทำงาน** + จุดแดงติดตลอด — ผู้ใช้กดแล้วเงียบ
6. **ชิปโปรไฟล์ "Gold Lover" กดไม่ได้** (ไม่มีเมนู)
7. **แคปชันปุ่มแมว hero ทับซ้อน/โดนตัด**: บับเบิล "ทำไมพอร์ตถึงขาดทุน ช่วยดูหน่อยนะ?" ลอยทับรูปและโดนตัดครึ่งคำ (เห็นชัดใน screenshot ux-01)

### C. แท็บพอร์ต (หน้า default)
8. **Scenario Picker บังพอร์ต**: แถบ "โหมดจำลองพอร์ต" สูงใหญ่ 4 การ์ด ยาวเต็มบรรทัด อยู่เหนือตัวเลขพอร์ต — ผู้ใช้ต้องเข้าใจ "โหมดจำลอง" ก่อนถึงจะเห็นพอร์ตตัวเอง, การ์ดจริง (default) ไม่ควรกินพื้นที่เท่าการ์ดจำลอง
9. **CTA วินิจฉัยซ้ำ 4 จุด**: ปุ่มแมว top bar + ชิป "ให้ทีม Gold Assistant วินิจฉัยพอร์ต...?" ใน header พอร์ต + ปุ่มใหญ่ใน HomeView + quick prompt ใน ChatPanel — ข้อความเดียวกันโผล่ 4 ครั้ง
10. **ศัพท์การเงินไม่มีคำอธิบาย**: "กำไร/ขาดทุน (ยังไม่รับรู้)" — มือใหม่ไม่รู้ว่า realized/unrealized คืออะไร ไม่มี tooltip

### D. แท็บ Gold Assistant
11. **ช่องถาม 2 ที่ทำงานเดียวกัน**: กล่อง "ถามกล่องทีมช่วยวิเคราะห์..." ใน workspace + กล่อง "พิมพ์คำถามเกี่ยวกับพอร์ตทองของคุณ..." ใน ChatPanel ขวา — ผู้ใช้งงว่าควรพิมพ์ที่ไหน
12. **ระหว่างรัน ต้องเลื่อนลงเองเพื่อดูการ์ดรายละเอียด**: กราฟอยู่บน การ์ดอยู่ล่างสุด (ห่างเกิน 1 จอ) auto-scroll ถูกปิดเมื่อกราฟอยู่ใน viewport — ผู้ใช้พลาดขั้นตอนที่ 2-4
13. quick prompts ซ้ำ 2 ชุด (workspace + chat panel)

### E. แท็บวิเคราะห์/ข่าว/ตลาด
14. **ศัพท์สถิติแน่น**: Max Drawdown / Volatility / HHI / corr(ทอง, DXY) ไม่มีคำอธิบายภาษาคนใน cell หลัก (มี sub-label เล็กบางจุด), ย่อหน้า Behavior Gap ยาว
15. **พาดหัวข่าวโดน truncate**: `.truncate` ตัดหัวข่าวด้วย ... โดยไม่มีทางขยายดูเต็ม (HomeView + NewsList)
16. **ตารางตลาดใช้ย่อลับ**: "14 w. 2568" (สัปดาห์?) อ่านไม่ออก, ผสม พ.ศ./$/หน่วยโดยไม่อธิบาย

### F. มือถือ
17. **สถานะแชตเปิดค้างข้ามอุปกรณ์**: localStorage `ga-chat-open=1` จากเดสก์ท็อป → เปิดมือถือครั้งแรกเจอ overlay แชตเต็มจอบังเนื้อหาหมด ต้องกดปิดก่อนทุกครั้ง (ยืนยันจาก screenshot ux-09)
18. **ปุ่มลอยทับชิป**: FAB แชตทับแถว quick-prompt chips ด้านล่างบนมือถือ

### G. ความเชื่อมั่น
19. **ไม่มี disclaimer มองเห็น**: ข้อความปฏิเสธความรับผิดชอบซ่อนอยู่แท็บรายละเอียดโปรเจกต์เท่านั้น แต่ทุกแท็บโชว์ตัวเลข กำไร/ขาดทุนจริง
20. **ป้าย "จำลอง" ไม่สม่ำเสมอ**: บางจุดบอกข้อมูลราคาจริง, บางแท็บไม่มีป้ายแหล่งข้อมูลเลย

## สรุปแนวทาง (ต้องผ่าน deep research ยืนยันก่อนลงมือ)
- IA: ลด 8 แท็บ → กลุ่มชัด, แท็บแรกต้องเป็น "หน้าแรก" จริง
- ตัด dead controls ออกทั้งหมด (deletion is design)
- Scenario Picker → แถบกะทัดรัด/ปุ่มเลือก
- ช่องถามรวมเป็นที่เดียว + CTA เดียว
- ระหว่างรัน: กราฟ + สถานะย่อ sticky ให้เห็นความคืบหน้าโดยไม่ต้องเลื่อน
- ศัพท์การเงิน: เพิ่มคำอธิบายภาษาคนแบบ 1 บรรทัดใต้ค่า
- มือถือ: รีเซ็ต overlay แชตข้าม breakpoint, จัดวาง FAB ไม่ทับชิป
- Trust: disclaimer เห็นชัดในหน้าที่มีตัวเลข, ป้ายแหล่งข้อมูลสม่ำเสมอ
